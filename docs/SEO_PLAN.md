## 1. Анализ ниши и позиционирование

### 1.1 Что покупает целевая аудитория
- **B2B (70–80% выручки):** заводы, цеха, контрактные производства — закупают тоннами, нужны сертификаты, ГОСТ-аналоги, прайс, КП.
- **Мелкий B2B / частный заказ (20–30%):** мастерские, ремонт, хобби, монтаж — нарезка от 1 м, малый чек, нужна цена сразу.

### 1.2 Ключевые конкуренты в выдаче (на момент аудита)

| Сайт | Сильное у них | Чем берут трафик |
|---|---|---|
| globus-stal.ru | Большая таблица марок с ГОСТ/EN/ASTM + цены, 13-вопросный FAQ, 3500-4000 слов на категории | Полнота справочника + цены в таблице |
| metalinox.ru (НН) | Локализованный H1 «купить в Нижнем Новгороде», галерея сертификатов, CTA-кнопки | Гео + доверие |
| gsa.ru (СПб) | ГОСТ 4986-79 в каждом названии товара, русские аналоги в скобках (08Х18Н10), много фильтров | ГОСТы + русские марки |
| rtg-mps.ru | 3500–4000 слов на категорию, блок «С этим обычно покупают» (плита/штрипс/труба) | Длинные тексты + кросс-сейл |
| mpstar.ru | Таблицы цен по типоразмерам, явная марка-аналог в H1 | Цена + аналог |
| nerjstal.ru | «Бесплатная доставка» в H1, прайс по тоннам | Логистика как USP |

### 1.3 Главные пробелы конкурентов (где можно отжать)
- Почти ни у кого нет **актуальных цен на странице товара** — почти у всех «по запросу». Если мы будем держать цены — это сильное преимущество.
- Сертификаты обычно в виде картинок, без OCR и текстового пояснения — у нас есть шанс лучше работать с ГОСТ-контентом.
- Многие сайты построены на 1С-Битриксе и неоптимизированы технически — у нас лёгкий самописный движок без блота.
- Слабая локализация (Москва или Питер по умолчанию, без чёткой выдачи на города) — у нас уже 3 региона в топбаре, можно дожать.

### 1.4 Наше уникальное позиционирование (USP)
1. **Нарезка от 1 метра** — почти ни у кого нет, у нас на главной.
2. **Малая ширина — от 2,5 мм** — узкая ниша, мало конкурентов.
3. **3 склада: Нижний Новгород + Москва + СПб** — закрывает 80% спроса по логистике.
4. **Ответ за 15 минут** — измеримое обещание SLA в meta description.

## 2. Семантическое ядро

### 2.1 Кластеры запросов

**Кластер A — Коммерческие (трансакционные)** — главная цель ранжирования
- `купить ленту нержавеющую AISI {grade}`
- `лента AISI {grade} {толщина} мм цена`
- `лента нержавеющая {ГОСТ-аналог}` (например `12Х15Г9НД`, `08Х18Н10`)
- `штрипс нержавеющий AISI {grade}`
- `нарезка ленты нержавеющей в размер`

**Кластер B — Информационные / Top-of-funnel** — для контент-хаба
- `AISI 304 и AISI 316 в чём разница`
- `чем отличается 2B от BA поверхность`
- `какая нержавейка для пружин` → AISI 301
- `какая нержавейка для штамповки`
- `аналог AISI 304 ГОСТ`
- `магнитится ли AISI 304/316`
- `маркировка нержавеющей стали расшифровка`

**Кластер C — Локальные (гео) запросы**
- `лента нержавеющая в Нижнем Новгороде`
- `купить штрипс AISI 304 Москва`
- `нержавеющая лента СПб со склада`

**Кластер D — Низкочастотные хвосты по типоразмерам** — основа структуры товаров
- `лента AISI 304 0.3 мм`, `лента 304 0,5х10 мм`, `нагартованная BA` и т.д.
- Уже покрывается генератором карточек товаров (874 URL в sitemap.xml).

### 2.3 Что обязательно собрать через Wordstat / Keys.so вручную

Этот пункт — для отдельной ручной/SEO-агентской работы, в коде закрыть нельзя:

## 5. Контент-стратегия (контент-хаб)

Информационные запросы — это **холодный трафик**, который потом конвертируется через ретаргет и брендовый запрос. Конкуренты в нише почти не делают информационных статей — окно возможностей.

### 5.1 Раздел `/blog/` или `/spravochnik/`

Запуск через ~2–3 мес. Рекомендованная структура:

| Тема статьи | Объём | Целевой запрос |
|---|---|---|
| AISI 304 vs AISI 316 — в чём разница, что выбрать | 1500 слов | `aisi 304 vs 316`, `чем отличается 304 от 316` |
| Поверхности нержавейки: 2B, BA, No.4, Mirror | 1200 слов | `2b или ba нержавейка`, `поверхность ba что это` |
| Что такое нагартованная нержавеющая сталь | 1000 слов | `нагартованная сталь это`, `нагартованная или мягкая` |
| Аналоги AISI по ГОСТ — полная таблица | 800 слов + большая таблица | `аналог aisi гост`, `08х18н10 это aisi` |
| Как выбрать нержавейку для пружин | 1000 слов | `нержавейка для пружин`, `aisi 301 пружины` |
| Магнитится ли нержавейка | 700 слов | `магнитится ли нержавейка`, `aisi 304 магнитится` |
| Нержавейка для пищевого производства — какую выбрать | 1200 слов | `пищевая нержавейка`, `aisi 304 пищевая` |
| Нержавейка для морской воды | 1000 слов | `нержавейка для моря`, `aisi 316 морская вода` |
| Резка нержавеющей ленты — методы и точность | 800 слов | `резка штрипса`, `нарезка нержавейки в размер` |
| Хранение и упаковка нержавеющих лент | 600 слов | `хранение нержавейки`, `упаковка штрипса` |
| Сравнение AISI 201 и AISI 304 для пищевого | 1000 слов | `aisi 201 пищевая`, `201 или 304` |

**Темп:** 2–4 статьи в месяц. Лучше реже, но длиннее и с уникальными данными (фото производства, кейсы клиентов, замеры).

### 5.2 Внутренняя перелинковка из статей

- Каждая статья ссылается на 2–4 категории по теме (например, статья про пружины → /aisi-301/).
- Из категории — ссылка на 1 экспертную статью (блок «Полезные материалы»).
- Анкоры **разнообразные:** brand-anchor («Каталог AISI»), exact («лента AISI 304»), naked URL, кнопка-CTA.

### 5.3 Шаблон статьи в блоге (для копирайтера)

```

[Lead, 2-3 предложения — для какого читателя статья и что узнает]
```

### 8.2 Что усилить

## 12. Чего НЕ делать

- ❌ **Не использовать фейковые отзывы и рейтинги** — Google теперь жёстко определяет (Reviews update 2023+), Яндекс — через постпрогон поведенческих.
- ❌ **Не клоакать** контент для роботов и пользователей разный.
- ❌ **Не покупать пачкой по дешёвым биржам** (Sape, Trustlink) — это путь под АГС/Минусинск.
- ❌ **Не дублировать** Title/H1/Description между категориями (сейчас уникально — следить за этим при добавлении новых марок).
- ❌ **Не использовать `Disallow: /*?*`** без `Allow: /*?page=` — теряем пагинацию (сейчас правка применена).
- ❌ **Не плодить технические URL** без канонических ссылок (фильтры через GET без canonical → дубли).
